# Cybersecurity Learning Journey 🚀
My hands-on notes, commands, and lab practices.

## 1. Basic Linux Commands
- ip a : Check IP address and network interfaces.
- cd : Change directory.
- less : View large files page by page.
- grep : Search specific text/patterns in files.

## 2. Nmap Scanning Basics
- sudo nmap -sn <target> : Host discovery (ping scan).
- sudo nmap -sS <target> : SYN Stealth Scan.
- sudo nmap -p- <target> : Scan all 65,535 ports.
- sudo nmap -oA <output> : Save scan results in all formats.
